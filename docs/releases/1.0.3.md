# Notchlight 1.0.3

Fixes unnecessary startup work when the local Codex history contains old task logs.

## Fixed

- Old logs skipped at startup now stay skipped on subsequent activity checks,
  preventing their existing contents from being scanned as newly appended data.
- Activity checks read fresh file metadata so newly appended events and file
  truncation are detected promptly.
- New task-start and interruption events continue to update activity correctly.

## Performance and verification

In a controlled release benchmark with 256 unchanged old logs, the second check
went from reading **16.7 MB to zero bytes**, with median duration falling from
**90.9 ms to 3.0 ms** across three runs per version on the same Mac. This measures
the activity reader in isolation; full-app startup time, peak memory, and battery
impact were not remeasured. Animated Settings performance is unchanged by this fix.

All **126 automated tests passed**, including a new regression covering repeated
old-file checks, truncation, and appended lifecycle events. Release packaging,
the extracted app's signature, version, bundled legal documents, deployment
target, architecture, and archive checksum were verified.
