# Notchlight 1.1.1

Restores Codex usage refreshes after the desktop app's CLI packaging change.

## Fix

Recent desktop app builds place their Codex launcher at
`Contents/Resources/codex-cli/bin/codex`. Notchlight previously checked only the
older bundled location, so usage could become unavailable while activity
detection continued working.

Notchlight now finds the packaged launcher in both ChatGPT and Codex app bundles
under `/Applications` or your user's `Applications` folder. Older desktop
layouts, standalone CLI installations, and `PATH` discovery remain supported.

## Validation

All **176 automated tests passed**, including executable discovery regressions.
The updated reader successfully fetched live usage through the installed
desktop app's new launcher. The release archive's extracted signature, version
**1.1.1 (6)**, Apple Silicon architecture, macOS 14 deployment target, and
SHA-256 checksum were verified. Packaging also verified the bundled legal files.

Built and tested on **macOS 27 with Xcode 27 / Apple Silicon**. macOS 14/26 and
Intel have not been runtime-tested for this patch. No UI behavior was changed.

## Download and install

1. Download **`Notchlight-1.1.1-macOS-arm64.zip`** and unzip it.
2. Quit the older copy and replace it with **Notchlight.app** in Applications.
3. Open Notchlight. Your saved settings are retained.

Requires **macOS 14 or later**. The archive is **Apple Silicon only**, **ad-hoc
signed**, and **not notarized**, matching the previous release. If macOS blocks
the first launch and you trust the download, follow
[Apple's Open Anyway instructions](https://support.apple.com/en-us/102445).

Download `SHA256SUMS.txt` alongside the archive and verify it with:

```sh
shasum -a 256 -c SHA256SUMS.txt
```
