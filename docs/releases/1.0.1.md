# Notchlight 1.0.1

Notchlight is a native macOS notch border and
optional Codex activity/usage indicator.

## Included

- Adjustable border color, weight, spacing, progress endpoints, and glow.
- Optional Codex usage windows, activity color, busy glow, and idle visibility.
- Hover details, native notch menu, ruler ticks, and appearance controls.
- Optional swipe hiding and a permission-free desktop-transition fallback.
- Local performance diagnostics and user-initiated ZIP export.
- An offline Legal section with license, terms, privacy, and third-party notices.

## Download

Download `Notchlight-1.0.1-macOS-arm64.zip`, unzip it, and move `Notchlight.app`
to Applications. `SHA256SUMS.txt` provides the archive's SHA-256 checksum.
No local compilation is necessary.

This build is **Apple Silicon only**, **ad-hoc signed**, and **not notarized**.
macOS may block it on first launch. If you trust the download, follow
[Apple's Open Anyway instructions](https://support.apple.com/en-us/102445).
Do not disable system security globally. A Developer ID-signed and notarized
edition requires the maintainer's Apple Developer setup.

The deployment target is macOS 14. This release was built on macOS 27 with
Xcode 27; older supported OS versions and Intel Macs have not been runtime-tested.
Notchlight has not been submitted to or approved for the Mac App Store.

## Verification and screenshots

The release build passed 118 automated tests. Native checks covered all four
bundled legal documents, scrolling, minimum window sizing, and Done/Escape in
both the legal window and Settings sheet. Settings and legal views were checked
in light and dark appearances on macOS 27. See the
[README screenshots](../../README.md#screenshots); settings images use labeled
sample usage data.

## Known limitations

- Usage normally refreshes once per minute; activity checks run approximately
  every two seconds. They are indicators, not authoritative billing or task state.
- Codex activity uses local implementation details and may miss remote work or
  stop working after a Codex format change.
- Optional swipe monitoring uses undocumented event fields and may be affected
  by macOS updates.
- Notchlight requires your own Codex installation/sign-in for Codex features.
- Performance diagnostics are enabled by default and remain local. Disable them
  in Settings if you do not want recording; exported logs are not sent anywhere
  automatically.
