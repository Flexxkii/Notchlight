# Notchlight 1.3.0

- **Attention indicator:** an amber border for explicit local Codex approval
  and input requests, with hook setup that preserves existing configuration.
  One-time hook review in Codex is required.
- **Custom local signals:** a bundled command for builds, tests, and other
  scripts. Independent sources, automatic expiry, priority, and dismissal.
- **In-app updates:** release notes, signed feeds and downloads, and installation
  with relaunch through Sparkle. Automatic checks are opt-in.
- **Battery-aware effects:** optionally stop pulsing, glow, and animated notch
  transitions on battery power or in Low Power Mode, restoring saved appearance
  when full effects are available again.

macOS 14 minimum and Swift 6 are preserved. The downloadable build targets Apple
Silicon. It remains Apple Development signed, not Developer ID notarized.
Version 1.2.3 and earlier need this release installed manually once to gain the
updater. Later releases can be installed from Notchlight's update dialog.

See the [signal and power guide](../status-signals.md) for setup and limitations.
