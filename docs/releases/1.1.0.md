# Notchlight 1.1.0

**Ready when you sign in. Easier to discover. Lighter while it runs.**

This release adds launch at login and a first-run notch hint, improves how
Notchlight follows Codex activity, and removes repeated SwiftUI work from the
animated Settings preview.

## What's new

- **Launch at login:** enable **Settings → General → Launch at login** to start
  Notchlight when you sign in to your Mac. The checkbox follows macOS's current
  status and helps you open Login Items if approval is needed. It stays off
  unless you choose to enable it.
- **A welcoming first launch:** a brief “Click your notch” callout points new
  users to the menu. Open the menu, dismiss the hint, or let it disappear after
  12 seconds. Existing installations skip it, and completion is remembered.

## Improvements and fixes

- **Activity updates follow file changes.** Local Codex task starts, completions,
  and interruptions update the border through file notifications. A safety
  check runs about once a minute, with a two-second polling fallback when file
  watching is unavailable.
- **Less work for the Settings preview.** Core Animation drives the familiar
  glow without rebuilding the SwiftUI outline every frame. Hidden-window
  suspension and Reduce Motion behavior are preserved.
- **Automatic catalog recovery.** If Codex's local task catalog or WAL sidecar
  is temporarily unavailable, Notchlight retries with a delay starting at one
  second and increasing to at most 30 seconds. Recovery remains read-only.
- **Fewer redundant updates.** Unchanged activity snapshots no longer refresh
  the UI. Recovery handles replaced or truncated files, missed notifications,
  sleep/wake, and Codex restarts.
- **Expanded documentation** for features, login items, and activity tracking.

## Validation and compatibility

All **171 automated tests passed**. Release packaging, the extracted app's
signature, version **1.1.0 (5)**, bundled legal documents, architecture, minimum
OS version, and SHA-256 checksum were verified.

The native notch-hint fixture also passed presentation, placement, focus,
timeout, and no-replay checks. A fresh live Settings inspection was unavailable
because the Computer Use connection failed after relaunch.

Earlier controlled release fixtures measured the preview's visible-busy
app-process CPU at **23.135% before → 0.155% after**, and the isolated idle
activity detector at **0.394% → 0.044%**. These are separate synthetic scenarios
on the development Mac, not whole-system or battery-life measurements; results
will vary with hardware and workload.

Requires **macOS 14 or later**. Built and tested on **macOS 27 / Apple Silicon**
with Xcode 27. macOS 14/26, Intel, an actual logout/login cycle, and VoiceOver
speech have not been runtime-tested. Native login-item operations have automated
coverage using injected system operations; actual system registration remains
unverified. Earlier visual fixtures covered the notch hint and light/dark preview.

## Download and install

1. Download **`Notchlight-1.1.0-macOS-arm64.zip`** and unzip it.
2. Quit an older running copy, then move **Notchlight.app** to **Applications**,
   replacing the previous version if installed.
3. Open Notchlight. To enable automatic startup, open **Settings → General**.

The archive is **Apple Silicon only**, **ad-hoc signed**, and **not notarized**.
If macOS blocks the first launch and you trust the download, follow
[Apple's Open Anyway instructions](https://support.apple.com/en-us/102445).

Download `SHA256SUMS.txt` beside the archive and verify it with:

```sh
shasum -a 256 -c SHA256SUMS.txt
```
